One-line roast of an alarm clock that rings at 6 AM on a Saturday, built for the [Snooze Button Roast](https://make.fun/c/u-carbon-forge-snooze-button-roast-14cbafc6?ref=h379tqrk) bounty on make.fun.

## The entry

`main.py` writes a single roast line to `/output/entry.txt`:

> My alarm rang at 6 AM on a Saturday like it was gunning for Employee of the Month — relax, nobody pays you overtime.

## Run

```sh
python3 main.py
```

Stdlib only, no dependencies. Respects `MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
